# Share your XGO-Duck work

Use **English or Chinese**. We publish the content in the language you submit and do not translate it.

## Projects

Open the [project submission form](https://github.com/LuwuDynamics/xgoduck_community/issues/new?template=share-project-en.yml). Include a name, category, original project URL, short description, images and an optional video link. MakerWorld and other external platforms are welcome; you do not need a separate code repository or local build tools.

Categories: Structure, Firmware, Motion models, Audio & video.

## Duck showcase

Open the [duck sharing form](https://github.com/LuwuDynamics/xgoduck_community/issues/new?template=share-duck-en.yml). Include a title, short description and at least one image or video link. A project URL and code repository are not required. Your display name is optional.

Drag images into the form or paste public HTTPS image links. Up to 7 images are supported; the first becomes the cover.

## AI agents and pull requests

Copy the [agent submission prompt](docs/AGENT_SUBMISSION_PROMPT_EN.md), or use the copy button on the [English submission page](https://luwudynamics.github.io/xgoduck_community/en/contribute/#agent).

For a PR, add one Markdown introduction to `projects/` using the [project template](docs/PROJECT_TEMPLATE_EN.md) or [duck template](docs/DUCK_SHARE_TEMPLATE_EN.md). You can do this entirely on GitHub. Follow GitHub's prompts to fork the community repository and open a pull request; your original work can stay on MakerWorld or another platform.

English and Chinese field headings and category names are accepted. Keep the heading labels from your chosen template. The content itself stays in your chosen language.

## Updates and removal

Leave a request on the original submission, or open a PR updating or deleting the matching introduction. Maintainers handle removal in the repository. The original project remains on its original platform.
